DanLume 手机版 · 使用说明（1.3.2）
================================

【Android 安装包】
已附带 DanLume-1.3.2.apk（约 2.4MB，Android 7.0 及以上，已签名）。
1. 把 APK 传到手机，点击安装；首次要允许「安装未知应用」。
2. 打开后先进入「复旦身份验证」页：输入学号/工号与统一身份认证密码。
   这一步直接向学校新版 ID 系统（id.fudan.edu.cn）验证，不经过第三方。
3. 登录成功后会自动同步本学期课表、教务处通知和 eHall 账号信息。
4. 下次打开会自动恢复登录，不用反复输入；需要换账号到
   「设置 → 复旦账号 → 切换账号」。
5. 升级请覆盖安装同一签名的 APK；卸载会清空应用内数据（重要数据先导出备份）。

【手机邮箱（不需要电脑）】
1. 打开「邮箱 → 添加账户」。
2. 选 QQ / 163 / 126 / Gmail 预设，或手动填 IMAP / SMTP。
3. QQ / 163 / 126 要先去网页版开启 IMAP，并生成“授权码”，密码栏填授权码。
4. Gmail 要开启两步验证并生成“应用专用密码”；SMTP 用 587 + STARTTLS。
5. 点「测试」确认 IMAP / SMTP 都正常，再保存。
6. 账户保存在手机本机，密码用 Android Keystore 加密；收件、HTML、
   内联图片、附件、回复 / 转发、草稿 / 已发送都在手机上完成。

【需要电脑的地方（可选）】
复旦登录、课表、通知、eHall、邮箱都在 APK 内完成，不需要电脑。
只有公式页用 XeLaTeX 编译 PDF 才需要电脑装 TeX Live / MiKTeX，
并在「设置 → 本地服务」填 http://电脑IP:8787。

【网页版运行（不用 APK）】
1. 安装 Node.js 18+（https://nodejs.org）。
2. 双击「启动 DanLume 手机版.bat」，窗口会显示本机地址、局域网地址和二维码。
3. 手机连同一 Wi-Fi，扫码或输入地址即可；网页版同样需要先验证复旦身份。

【身份信息存在哪】
- APK：学号/密码用 Android Keystore 的 AES-GCM 加密后存在应用私有
  SharedPreferences（可理解为安卓的“注册表”），系统其他应用读不到。
- 网页版：账号密码用 AES-256-GCM 加密存在电脑的 data/fudan.json。
- 退出登录会清除保存的凭据；不勾选“记住我”则只在本次运行内有效。

【AI 助手】
- 应用不内置服务地址、模型名或访问密钥。
- 先去「设置 → AI 设置」填写自己的 OpenAI 兼容服务地址、访问密钥和模型名。
- DeepSeek 服务地址填 https://api.deepseek.com/v1，模型填 deepseek-chat 或 deepseek-reasoner。
- AI 请求会先走本机/电脑的本地服务转发；iPhone 网页版需要电脑上的服务保持运行，否则可能提示 Failed to fetch。
- Lume 可以「动手」：新建日程、查日程、删除日程、写备忘、查天气、汇总今天安排。
- 删除日程直接说“删除今天下午的评审会”；同名多条时它会先列出 id。

【日历显示】
- 课表同步的课程统一为青绿色；个人任务默认紫色，也可在新建时改颜色。
- 新建日程用当天标题右侧的「新建」，右下角不再有悬浮加号。
- 长按首页或日历里的日程，可以直接选择编辑或删除。

【数据与备份】
- 日程、备忘、文档、文献、对话存在手机本地（IndexedDB）。
- 清理应用数据 / 清除站点数据会清空，请在「更多 → 导出备份」定期存 JSON。
- 邮箱账号与密码在 APK 里用 Android Keystore 加密保存；网页版才存在电脑
  data/mail-accounts.json（AES-256-GCM 加密）。

【常见问题】
Q: 登录提示“验证码/二次验证”？
A: 学校在多次失败或换设备时要求额外验证。请先在手机浏览器登录一次
   id.fudan.edu.cn，完成验证后回到应用重试。

Q: 课表没有同步出来？
A: 确认登录成功、学历阶段（本科/研究生）选对；学校课表页面结构变化时
   会提示同步失败，登录本身不受影响。

Q: 通知是空的？
A: 登录后到「通知」页点右上角刷新，或到「设置 → 复旦账号 → 通知」。

Q: 邮箱测试失败？
A: QQ/163/126 要用“授权码”而不是网页密码，并先在网页版开启 IMAP/SMTP；
   端口：IMAP 993（SSL），SMTP 465（SSL）或 587（STARTTLS）。
   网易邮箱如果提示 Unsafe Login，应用已经自动发送客户端 ID，仍失败请换授权码重试。
   Outlook / Office 365 多数学校已禁用基础认证，暂不支持账号密码直连。

Q: 手机上打不开网页版？
A: 确认手机与电脑同一 Wi-Fi；Windows 防火墙放行 Node；
   地址用 http://电脑IP:8787/。
